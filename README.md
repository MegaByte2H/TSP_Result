# ПОТМ
## Структура проекта

* `main.py` - точка входа в программу и настройка параметров маршрута;
* `genetic.py` - реализация генетического алгоритма поиска маршрутов;
* `core.py` - общие функции оценки маршрутов, персонализации и модели сытости;
* `data.py` - загрузка и подготовка данных из базы;
  
* `tourism_kazan_full.db` - база данных туристических объектов.
